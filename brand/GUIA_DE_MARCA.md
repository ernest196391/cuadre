# Cuadre — guía práctica de marca

## Idea central

Cuadre es una herramienta de contabilidad operativa. El símbolo representa dos registros que se acercan y encajan en un centro exacto. No representa criptomoneda, riqueza ni crecimiento financiero.

## Logo

- Usar el logotipo horizontal en encabezados web, documentos y presentaciones.
- Usar el símbolo solo en favicon, icono de aplicación y espacios menores de 120 px.
- Mantener alrededor del logo un área libre igual al ancho del vacío central del símbolo (1x).
- Tamaño mínimo recomendado: 24 px para el símbolo y 96 px para el logotipo horizontal.
- A 16 px usar únicamente el símbolo simplificado; nunca el wordmark.

## Colores

| Uso | Color | HEX |
|---|---|---|
| Acción principal | Azul oficio | `#2457D6` |
| Texto principal | Grafito | `#17202A` |
| Texto secundario | Pizarra | `#4B5563` |
| Bordes | Niebla | `#E7EBF0` |
| Fondo claro | Marfil | `#F8F7F3` |
| Superficie | Blanco | `#FFFFFF` |
| Éxito | Verde oficio | `#18794E` |
| Error | Rojo control | `#C43D4B` |
| Advertencia | Ámbar | `#B86B00` |
| Información | Azul información | `#246BCE` |

El azul se reserva para acciones, selección y datos destacados. Los colores funcionales solo comunican estados.

## Tipografía

- Marca e interfaz: IBM Plex Sans.
- Montos, tasas, saldos y columnas comparables: IBM Plex Mono.
- Activar `font-variant-numeric: tabular-nums slashed-zero`.
- H1: 32/38 Semibold; H2: 22/28 Semibold; cuerpo: 16/24 Regular; etiquetas: 12/16 Medium; montos principales: 32/36 Medium.

Los enlaces oficiales para descargar las familias están en `06_Fonts/FUENTES.md`.

## Voz de producto

Directa, breve y específica. Describe lo que ocurrió y su consecuencia contable.

- Botón: “Guardar entrega”.
- Confirmación: “Entrega registrada. El saldo y el margen ya están actualizados.”
- Estado vacío: “Aún no hay movimientos esta semana.”

Evitar “revoluciona”, “haz crecer tu riqueza”, “inteligente”, “mágico” y cualquier promesa publicitaria.

## Web y móvil

- Una acción principal por pantalla.
- Montos alineados a la derecha y con cifras tabulares.
- Área táctil mínima: 44 × 44 px.
- Contraste mínimo WCAG AA.
- Mantener navegación y registro operativo utilizables con conexión lenta.
- No depender solo del color: acompañar estados con texto o iconos.

## Redes sociales

Las publicaciones deben educar o demostrar trabajo real: cierres semanales, control de margen, seguridad de datos y registro operativo. No usar fotos de monedas, fajos de billetes, gráficos ascendentes ni lenguaje de riqueza.

## Usos incorrectos

No deformar, girar, aplicar sombras, cambiar proporciones, usar degradados, añadir colores o colocar el logo sobre fondos sin contraste. No combinar con burdeos, dorado, triángulos o serif clásica.
